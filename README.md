# 圓心角兩倍於圓周角（互動 Web App）｜馬Sir教室

中三／中四「圓的性質」：拖動圓周上的 A、B、C，即時看到 ∠AOB ÷ ∠ACB = 2，並用「證明模式」展示三種情況的證明。

網址：https://masir-math.github.io/circle-angle-at-centre/

## 功能
- 探索：拖 O 可移動整個圓（另有半徑滑桿及「重設」），A、B、C 可用滑鼠／觸控拖動，或 Tab 揀點後用方向鍵（Shift＝5°）移動。紅＝被對住的弧 AB，藍＝圓心角，綠＝圓周角。
- 即時顯示 ∠AOB、∠ACB 及比值（永遠 2.00）；C 在劣弧上時自動改用反角，並提示「弧換咗」。
- 證明模式：橙色輔助線 CO 延長至 D，標出等腰三角形底角 α、β 及外角 2α、2β；自動判斷情況一（O 在角內，相加）、情況二（O 在邊上，直徑）、情況三（O 在角外，相減），並顯示對應證明及數值。
- 預設：O 在角內／O 在邊上／O 在角外／反角／AB 為直徑。
- 挑戰：6 題（由 7 題題庫隨機抽），即時對錯、提示、針對常見錯誤（倍數反轉、忘記反角、角外要相減）的回饋；分數 10／7／5，連勝 3 題加倍。

## 本機預覽
直接雙擊 `index.html`（單檔、離線可用；KaTeX 已內嵌，即使載入失敗亦會以純文字顯示公式）。

## 放入 Google Sites
插入 → 嵌入 → 「按網址」，貼上上面網址；把嵌入框拉高至約 1100–1400 px（窄框時版面會變成上下排列）。如學校網絡或 Sites 顯示有問題，另加一個按鈕／連結「在新分頁開啟」指向同一網址。

## 課堂用法建議
1. 探索模式先讓學生拖 C，觀察比值不變；再把 C 拖到劣弧，討論「弧換咗」。
2. 開證明模式，依次按三個情況預設，讓學生口述 α、β 及外角步驟。
3. 最後做挑戰（約 5–8 分鐘）。投影時可用瀏覽器放大（Ctrl +）。

## 限制
- 唔收集任何學生資料，冇 cookies／localStorage；分數重新整理即清除。
- 度數顯示至 0.1°；拖動時接近直徑（±1.5°）會自動吸附，以便展示情況二。三點之間最少相隔 4°。
- 挑戰題圖只作示意，未必按比例。
